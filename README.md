# Learning Journey

A simple iOS app that helps you build a learning habit. Set a goal, log each day you learn, and watch your streak grow on a yearly calendar.

## Main Features

- Set a learning goal and choose its duration (Week, Month, or Year)
- Log a day as "Learned" once per day
- Freeze a day when you can't learn (limited per week, month, and year)
- Streak resets if more than 32 hours pass without learning or freezing
- 12-month calendar view: orange = learned, blue = frozen
- "Well done" screen when you complete your goal, and "Goal not met" screen when the streak breaks
- Light and Dark mode support
- Liquid Glass design
